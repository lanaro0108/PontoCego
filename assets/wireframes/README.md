# Wireframes do Ponto Cego

Representações de baixa fidelidade, com dados fictícios, do fluxo proposto para o MVP.

- **Mobile:** Início, Ocorrências, Novo relato, Detalhes.
- **Web:** Dashboard, Gestão de ocorrências, Detalhe/triagem.

Os arquivos SVG são editáveis como imagens vetoriais e servem como base de comunicação, não como protótipo interativo. Os PNGs correspondentes são exportados automaticamente pelo workflow do GitHub.

**Nota:** estes wireframes vetoriais são reconstituições dos fluxos discutidos; não são cópias exatas dos primeiros esboços PNG enviados na conversa.
